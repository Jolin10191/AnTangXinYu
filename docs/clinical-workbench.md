# 浏览器医护工作台

入口：本机后端 `/clinician`。运行 `bash scripts/dev-api --base-only` 后，可从本机浏览器打开 `http://127.0.0.1:8000/clinician`。手机端与浏览器共用当前本地后端和数据库；本次未发布线上。

## 已实现

| 功能 | 行为 |
| --- | --- |
| 个人医护登录 | 仅当前有效医护身份可读取患者数据，默认显示已授权患者 |
| 患者列表 | 姓名及账号 ID，可搜索、分页、打开详情 |
| 时间范围 | 7、14、30、90 天或自定义，按浏览器时区显示 |
| 血糖变化 | 保存的手工和报告记录、数量/均值/最小最大、单位切换、最近 100 条明细；曲线最多 5000 条，截断时明确提示 |
| 数据连续性 | 仅连接同来源且间隔不超过 6 小时的相邻血糖记录，缺失不补值；离散记录不推算 TIR 或连续低血糖事件 |
| 手环观测 | 当前同步到后端的 Zepp/Health Connect、Gadgetbridge 分开显示心率、步数、睡眠和血氧；不把手环观测当作血糖 |
| 健康档案 | 当前已维护的基础信息与健康事实，只读 |
| 全部患者 | 已审核医护个人登录后输入统一密码解锁，不设置自动过期，仅当前登录会话可用 |
| 统一密码管理 | 研发管理个人账号登录，输入自身密码后设置/修改统一密码，旧解锁立即失效 |

全部患者范围由用户明确要求，与单个患者授权独立：患者撤销个人授权后，普通范围下一次查询不可访问；医护若仍具有有效的全部患者解锁，可在全部患者范围继续读取。每次查询均在服务器验证角色、登录会话和当前统一密码版本，并记录个人账号审计。共享密码不能使患者或研发账号获得医护读取权限。

解锁连续 15 分钟内累计 5 次错误后限制该个人账号验证。退出、角色降级、会话失效、密码修改均使原解锁不可用。浏览器不把令牌或密码放入本地持久存储，患者数据响应禁止缓存；退出和查询被拒绝后清除显示数据。

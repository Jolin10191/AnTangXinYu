# 用户权限与患者数据管理初步方案

日期：2026-10-09；更新：2026-10-15。角色与患者授权第一批已实现，隔离自动化验收与发布情况见 [交付说明](../patient-access.md)；后续数据扩展与预测仍为候选。

## 目标与现有基础

优先推进近期任务第 3 项，在现有账户、健康档案、手环数据和 Agent 基础上，补充角色权限与患者数据管理，为第 2 项血糖预测提供数据接口。

现有代码已提供：

- `api/src/antang_api/routers/auth.py`：注册、登录、刷新、退出、当前用户查询。
- `api/src/antang_api/models/user.py`：用户与登录会话；已增加业务角色。
- `api/src/antang_api/routers/health_profile.py`：当前用户的健康档案、设备数据导入及看板。
- `api/src/antang_api/health_profile/wearable_dashboard.py`：近 30 天设备统计与趋势，按来源区分。
- `api/src/antang_api/tools/wearable.py`：Agent 查询当前用户设备数据，支持最新记录、详情、时间范围和每日汇总。
- `api/src/antang_api/main.py`：上述工具与健康档案 Agent 已注册到 Core Agent。

当前 App 主要面向患者；完整医护工作台、研发数据工作台、公开 CGM 数据接入和预测服务仍待开发。已有图片/PDF 解读不能等同于结构化 CGM 时序导入。保留的 `today/demo-health.ts` 是手写演示数组，不是公开数据集。

## 第一批：角色与患者访问关系

已按确认范围实现普通注册固定患者、维护者赋予医护/研发身份、患者授权和撤销、医护授权患者列表及只读详情。患者从现有 App 的侧边栏管理授权，医护登录同一 App 查看有效授权患者。具体接口、维护命令、验收和部署前提统一见 [角色与患者授权](../patient-access.md)。

## 第二批范围：患者数据与可视化

后续复用现有健康档案和设备看板，扩展时间范围、趋势、最近同步时间与缺失数据提示。第一批医护只读详情已在现有 App 接入；独立 Web 工作台不在本批范围。

CGM 数据接入作为下一条独立流程：

1. 先选一个公开数据集和一个导入格式，确认获取条件、患者类型及可用模态。
2. 研究受试者 ID 与真实账户 ID 分开；公开受试者不直接绑定到真实患者账户。
3. 保存数据集/版本、受试者 ID、观测时间、血糖值、原始单位及来源；单位转换、去重和时间检查由程序执行。
4. 公开数据演示使用明确的研究受试者和数据来源标记，不混入患者真实健康档案、陪伴记忆或主动关怀。
5. 曲线展示时间范围、单位与缺失区间。无新采样时展示末次记录时间，不称为实时血糖。
6. 演示数据回放和真实手环同步分别展示；不同受试者的数据不能直接配对用于训练或测试。

## 第 2 项的简要衔接

多模态预测的候选输入是历史血糖，以及同一受试者、同一时间范围内实际可取得的饮食、胰岛素、活动等信息。具体输入以数据集字段为准，先确定糖尿病类型和目标人群，不能将不同人群数据直接混为同一实验结论。

第一步做历史血糖单模态基线（例如最近值保持基线及一个时序模型），候选预测跨度为 30/60 分钟；随后在相同划分下逐项加入可用模态，做增量与消融比较。

采用时间划分评测患者内预测；跨患者泛化另设受试者隔离测试。归一化和插补参数只由训练集确定，不使用预测时刻之后尚未知的信息。初步报告 MAE、RMSE，并说明样本量、缺失情况和评测范围。

模型输出通过独立预测接口返回预测时间、模型版本和结果来源，Agent 查询与解释结果。时序预测模型与现有多模态对话 Agent 分别承担数值预测和交互职责。实测数据进入后，先独立测试，再讨论是否需要个体化训练。

## 依据与候选决策

- 官方依据：[FastAPI 认证示例](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/)说明身份认证实现；[OWASP 授权建议](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)强调逐请求检查权限，并考虑角色之外的资源关系。
- 代码依据：当前健康档案接口和 Agent 设备工具都从认证上下文取得当前用户 ID，已有用户数据隔离基础。
- 自定义候选：单角色起步、患者主动授权、医护首批只读、研发使用独立研究数据。收益是第一批范围可控且能复用已有服务；代价是尚不支持完整医院组织关系、多身份与医护编辑业务，适用于当前课题原型。
- 数据集候选：[ShanghaiT1DM/ShanghaiT2DM 论文](https://www.nature.com/articles/s41597-023-01940-7)、[OhioT1DM 官方说明](https://webpages.charlotte.edu/rbunescu/data/ohiot1dm/OhioT1DM-dataset.html)。当前未下载、未完成字段核对、未训练模型。

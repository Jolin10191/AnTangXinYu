### 下一次复现与验收

| 场景 | 应验证的行为 |
| --- | --- |
| 同姓名、不同登录用户名 | 姓名本身不应阻止注册 |
| 不同姓名、同登录用户名 | 明确提示账号冲突，不创建重复账号 |
| 冲突报错后修改为新用户名 | 加载状态恢复，再次提交可以成功 |
